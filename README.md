## 🚀 Featured Projects

### 🩺 DermAI — Skin Disease Classifier

An end-to-end deep learning application for classifying **22 dermatological conditions** from clinical images.

### Key Results

* 📊 Trained on **11,000+ clinical images**
* 💾 Dataset size: **1.36 GB**
* 🎯 **82.4% Top-3 accuracy**
* 📈 **0.94 one-vs-rest AUC**
* 🧠 **EfficientNetB5** transfer learning
* 🔄 **8-pass Test-Time Augmentation (TTA)**
* 🔍 **Grad-CAM** for model interpretability
* ⚡ **<2s inference latency**
* 📦 **1.2GB+ model weights** managed using Git LFS

### Technical Implementation

* Two-stage **transfer learning**
* Frozen-backbone initialization
* Fine-tuning of the **last 150 layers**
* MixUp augmentation
* Label smoothing
* Cosine annealing with warm restarts
* Per-class evaluation metrics
* Confidence scoring
* Flask REST API
* HTML/CSS/JavaScript frontend
* Docker containerization
* Hugging Face Spaces deployment

🔗 **[GitHub Repository](https://github.com/Gupta-Tarun7/Skin_Disease_Classifier)**
🌐 **[Live Demo](https://huggingface.co/spaces/Gupta-Tarun/dermai-skin-classifier)**

### 🤖 Medical Chatbot

A **Retrieval-Augmented Generation (RAG)** medical chatbot that retrieves relevant information from medical documents before generating context-aware responses.

### Tech Stack

`Python` `LangChain` `Hugging Face` `Pinecone` `Groq` `Flask` `Render`

### Key Features

* 📚 Medical PDF document processing
* ✂️ Recursive text chunking
* 🧠 Hugging Face embeddings
* 🔎 Pinecone vector similarity search
* 🤖 Groq LLM inference
* 🔗 Retrieval-Augmented Generation pipeline
* 🌐 Interactive Flask web application
* 🚀 Production deployment using Render and Gunicorn

### RAG Pipeline

```text
Medical PDF
     ↓
PyPDFLoader
     ↓
Text Chunking
     ↓
Hugging Face Embeddings
     ↓
Pinecone Vector Database
     ↓
Similarity Search
     ↓
Retrieved Context
     ↓
Groq LLM
     ↓
AI Response
```
